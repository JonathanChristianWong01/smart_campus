# Input Program (stdin)

Input program digunakan untuk memasukkan data sebelum kode dieksekusi.

## Cara penggunaan
1. Buka menu Kompiler.
2. Pilih bahasa pemrograman.
3. Masukkan kode program.
4. Isi kotak Input program (stdin).
5. Tekan Jalankan.

## Bahasa yang didukung
- C++: cin atau getline.
- Python: input().
- PHP: fgets(STDIN).
- JavaScript Node.js: membaca standard input melalui modul fs.

## Batasan
Semua input dikirim sekaligus sebelum eksekusi.
Fitur ini bukan terminal interaktif.

Program harus menangani input kosong atau habis
agar tidak terus mengulang dan mencetak keluaran.

HTML/CSS/JavaScript pada preview browser menggunakan
elemen input HTML dan event JavaScript, bukan stdin.
