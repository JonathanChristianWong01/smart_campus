Cara Mengunggah Tugas ke GitHub (3 langkah)
1) Inisialisasi & commit
git init
git add .
git commit -m "Tugas 000100 - Nama Mahasiswa"

2) Sambungkan ke GitHub
git branch -M main
git remote add origin https://github.com/USERNAME/NAMA-REPO.git

3) Kirim
git push -u origin main
